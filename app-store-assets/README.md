## ⚠️ يحتاج قراراً منك قبل المتابعة
**التصميم الحالي اقتصاص محسَّن من صورة الغلاف الترويجية، وليس تصميماً احترافياً مخصَّصاً للأيقونة.**
أنصح بشدة بتصميم أيقونة مبسَّطة فعلياً (رمز واحد مميّز — مثلاً الكأس فقط بخطوط بسيطة، بلا لاعبين ولا خلفية معقّدة) مع مصمم جرافيك محترف قبل الإرسال النهائي للمتاجر. هذا ليس عائقاً للاختبار الآن، لكنه مهم لجودة الانطباع الأول أمام الجمهور والمتجر نفسه.

## ❌ غير جاهز بعد — يحتاج عملاً بشرياً/إدارياً منفصلاً عن البرمجة

### محتوى المتجر (نصوص وصور)

- [ ] لقطات شاشة فعلية بمقاسات كل جهاز (لا يمكنني التقاطها آلياً — تحتاج تشغيل الموقع فعلياً على جهاز حقيقي والتقاط الشاشة)
- [ ] Feature Graphic لجوجل بلاي (1024×500 — بانر ترويجي أفقي، يحتاج تصميماً منفصلاً)

### إلزامي قانونياً
- [ ] **سياسة خصوصية منشورة برابط عام** (كلا المتجرين يرفضان التطبيق بدونها) — تحتاج ذِكر بيانات: أسماء اللاعبين، الصور المرفوعة، التصويت، أي بيانات تُجمع
- [ ] تصنيف عمري للمحتوى (Content Rating) عبر استبيان كل متجر

### تقني إضافي (بعد اتخاذ القرار بالمتابعة)
- [ ] تغليف الموقع عبر Capacitor أو ما شابه لإنتاج ملفي .ipa و.apk حقيقيين

- [ ] حساب Apple يتطلب جهاز Mac فعلي (أو خدمة سحابية بديلة) لعملية البناء والتوقيع
